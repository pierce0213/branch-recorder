# 每日分支记录器

一天一棵分支树：随手记、随时翻、随手整理。**单文件、零依赖、离线可用**。

---

## 两个版本

| 版本 | 路径 | 说明 |
| --- | --- | --- |
| **桌面版** | `测试版/每日分支记录器-测试版.html` | 单文件，双击即用，功能最全 |
| **安卓版（PWA）** | `安卓版/index.html` | 移动端改造版，配 Service Worker + 图标，可装到手机主屏 |

两个版本相互独立，改一处不要顺手改另一处。

## 功能

- **画布 ⇄ 大纲双向联动**：节点即分支，层级、归属一眼看清
- 卡片折叠 / 展开两态；一级分支配色（连线也跟着配色）
- **一张卡放多张图**：1 张全宽 / 2 张两列 / 3 张一行 / 4 张 2×2 / 5 张以上九宫格，超过 9 张时第 9 格盖「＋N」
- **新建分支时镜头平滑腾空间**：卡片贴近屏幕底部也能完整带进视野
- 命令面板（`Ctrl/Cmd + K`）、锁定父节点连续拆分、整理布局（温和 / 彻底）
- 日历热力图、Markdown / OPML / 长图导出
- 安卓版额外支持：双指缩放、长按拖拽、断网可用、添加到主屏

## 快速开始

**桌面版**：直接双击 `测试版/每日分支记录器-测试版.html`。`file://` 打开即可用，无需任何服务。

**安卓版**

- 本地预览：双击 `安卓版/index.html`（`file://` 下不注册 Service Worker，功能不受影响）
- 装到手机主屏：需要 https。用手机 Chrome 打开 `安卓版/` 目录对应的在线地址，选「添加到主屏幕」

## 数据

所有记录保存在浏览器 `localStorage` 里，**不上传任何服务器**。换设备或换浏览器数据不互通，请用导出功能自行备份。
