# 每日分支记录器

一天一棵分支树：随手记、随时翻、随手整理。**单文件、零依赖、离线可用**。

> **要电脑和手机互通，请用在线版：<https://branch-recorder.app.workbuddy.host/>**
> （云服务的登录接口按域名做精确校验，只有这个域名能登录；GitHub Pages 和 `file://` 都会被拒。）

---

## 两个版本

| 版本 | 路径 | 说明 |
| --- | --- | --- |
| **桌面版** | `测试版/每日分支记录器-测试版.html` | 单文件，双击即用，功能最全 |
| **安卓版（PWA）** | `安卓版/index.html` | 移动端改造版，配 Service Worker + 图标，可装到手机主屏 |

两个版本相互独立，改一处不要顺手改另一处。
发布用的在线包 `online/` 是**生成物**（见下文「在线版发布包」），不要手改。

## 功能

- **画布 ⇄ 大纲双向联动**：节点即分支，层级、归属一眼看清
- 卡片折叠 / 展开两态；一级分支配色（连线也跟着配色）
- **一张卡放多张图**：1 张全宽 / 2 张两列 / 3 张一行 / 4 张 2×2 / 5 张以上九宫格，超过 9 张时第 9 格盖「＋N」
- **新建分支时镜头平滑腾空间**：卡片贴近屏幕底部也能完整带进视野
- 命令面板（`Ctrl/Cmd + K`）、锁定父节点连续拆分、整理布局（温和 / 彻底）
- 日历热力图、Markdown / OPML / 长图导出
- **学习线**：跨天回看每天记了什么；用一条「线索」把同一主题的多天记录串起来
- **待续 / 承接**：没做完的标一下，第二天一键「带到今天」，接着昨天的进度往下做
- **安卓版是「列表优先」，不是把电脑版缩小**：打开就是今天的大卡片列表，不用拖画布、不用捏合缩放
- 安卓版其他：断网可用、添加到主屏、双指缩放、长按拖拽（在「看树」页签里）

## 快速开始

**桌面版**：直接双击 `测试版/每日分支记录器-测试版.html`。`file://` 打开即可用，无需任何服务。

**安卓版（默认就是手机版式，不是电脑版缩小）**

- 打开就是**今天的大卡片列表**：一列一行，点一下从底部弹出编辑面板；点 `‹` `›` 或左右滑换天
- 层级用**缩进 + 折展**表示（点箭头收起子分支，箭头上的数字是里面有多少条）
- 底部 5 个入口：**今天 / 记录 / ＋ / 学习线 / 看树** ——「看树」才是那块无限画布，
  想看整体结构或整理布局时切过去；日常记东西走列表
- 昨天没做完的标过「待续」，第二天打开列表顶上会浮出一条「带到今天」，点一下就接上
- 本地预览：双击 `安卓版/index.html`（`file://` 下不注册 Service Worker，功能不受影响）
- 装到手机主屏：需要 https。用手机 Chrome 打开 `安卓版/` 目录对应的在线地址，选「添加到主屏幕」
- 已装好的可以直接用 `分支记录-1.0.apk`：它是个 WebView 壳，加载的就是上面那个在线地址，
  所以**网页改了不用重装 APK，打开就是新版**

## 学习线：第二天怎么接上第一天

学一个软件、读一本书这种跨天的事，靠三样东西串起来。

**① 标「待续」** —— 哪条今天没做完，选中它 → 详情面板 →「标为『待续』」。
卡片上会多出一个黄色的「待续」小标。

**② 第二天点「带到今天」** —— 打开新的一天时，画布顶部会浮出一条提示：

> `10-06 还有 2 项标着「待续」，今天接着做？` 〔带到今天〕

点一下，这几条就接到今天了：

- 标题前面加「承接：」，卡片上带「来自 10-06」的小标
- **昨天那份原封不动留在昨天**（是复制，不是搬走）
- 只承接没做完的那几条，连同它们的子分支一起
- 今天这条的时间 / 评分清空 —— 那是今天的账，昨天的时段对今天没意义
- 详情面板里有「回原文看看」，点一下跳回昨天那条，对照上下文

不想带就点提示条右边的 ×，它今天就不再冒出来。同一天也不会重复提示已经带过的。

**③ 线索：把同一个主题的多天串起来** —— 选中卡片 → 详情面板 →「学习线」里选一条线索，
或点「＋ 新线索」建一条（比如「学 Photoshop」）。之后点左侧工具条的**学习线**：

- **按天**：一条竖着的时间轴，每天一段（日期 · 周几 · 几项 · 多久），条目按时段排序、按树形缩进
- **按线索**：一条线索一路铺开，天与天之间连着看，一眼知道「这个主题学到哪了」
- 顶部可按线索筛选；汇总条给出「几天 · 几项 · 总时长 · 几项待续」
- 点任意一行 → 跳到那天的画布并选中它，接着编辑

> **数据兼容**：线索 / 待续 / 承接这三个字段是「用到了才写」。没用过这些功能的卡片，
> 存出来的 JSON 和以前一字不差 —— 云同步的节点指纹按 `JSON.stringify` 算，
> 所以不会因为加了这个功能就把整库数据重推一遍。
>
> **时长按并集算**：父分支 `07:30–11:30` 里已经含了子分支 `07:30–09:30`，
> 逐个相加会算出「一天 25 小时」这种假数，所以同一天的重叠时段只计一次。

## 数据

所有记录默认保存在浏览器 `localStorage` 里，**没登录就不会上传任何服务器**。换设备或换浏览器数据不互通，请用导出功能自行备份。

### 云同步（电脑 ↔ 手机）

两版都带云同步：点顶栏的**云朵图标**，用邮箱开个账号（邮箱验证码注册），
电脑和手机登录同一个账号，记录就通了。

- **只在官方在线地址上能用**：<https://branch-recorder.app.workbuddy.host/>。
  云服务按 `Origin` 精确匹配，别的域名（GitHub Pages）会拿到 `403 access_denied`，
  `file://` 双击打开的页面浏览器根本不让它连服务器。不在官方地址时面板会直接提示，不用等到报错。
- 按天分片存：两台各推各改过的日子，A 在 10 号写、B 在 11 号写互不影响
- 同一天里**两台各自新建的卡片都会留下**；同一张卡两边都改过时留你当前这台设备上的那版
- 没登录 / 断网 / 离线时一切照旧走本机存储，只是不同步
- 云端表 `day_books` / `app_meta` 开了行级安全：未登录时读写都返回 `42501 permission denied`

依赖 `wbcloud-sdk.js`（WorkBuddy 云服务 SDK 的 IIFE 包，66 KB，与页面同目录一起发布）。
升级：重新下载 `index.global.js` 覆盖即可。

### 在线版发布包

发布到官方域名的是 `online/`，**由脚本生成、已在 `.gitignore` 里**，不要手改里面的文件：

```
online/
├── index.html            # 手写入口页（手机 UA 自动跳 m/），构建脚本会保留它
├── pc.html               # ← 测试版/每日分支记录器-测试版.html
├── wbcloud-sdk.js
└── m/                    # ← 安卓版/
    ├── index.html  manifest.webmanifest  sw.js  wbcloud-sdk.js  icons/
```

改完两版源码后重新生成并发布：

```bash
node 测试版/.audit/build-online.mjs .      # 重建 online/
```

然后用「发布应用」能力把 `online/` 发布出去，**必须复用云服务给这个应用的
`appId`（`wbapp_Cv4QSaY9b8au6ATSb6YIZ0`）**——新建应用会换域名，云登录就断了。
